🎨 Visual Aesthetic: "Soft Enterprise"
The UI leans heavily into Soft UI and Minimalism. It avoids the harsh borders of older medical software, opting instead for a breathable, "airy" feel that reduces cognitive load for busy medical staff.

Glassmorphism & Soft Depth: Notice the subtle drop shadows on the cards (Total Drugs, Prescription Queue). This creates a layered effect without using heavy lines, making the interface feel modern and high-end.

Rounded Geometry: High corner radius (around 12px to 16px) on containers and buttons. This "rounds off" the clinical coldness, making the software feel more approachable and user-friendly.

🏛️ Layout & Architecture
The layout follows a Standard Three-Column Dashboard pattern:

Navigation Sidebar (Left): Uses a light background with clean, line-based iconography. The active state (Pharmacy) is highlighted with a soft pill-shaped background.

Summary Layer (Top): High-level KPIs (Key Performance Indicators) are placed front and center to give the pharmacist an instant snapshot of inventory health.

Data Visualization (Center/Right): Splitting the view between a "Prescription Queue" (Actionable tasks) and "Stock Alerts" (Critical information) ensures the user knows exactly what needs attention first.

📑 Typography & Color Theory
The UI uses Semantic Coloring to communicate urgency without words:

The Palette: A foundation of Slate Blue and Teal suggests stability and cleanliness.

Status Indicators: * Green (Ready/Collected): Positive reinforcement.

Amber/Orange (Pending/Low Stock): "Proceed with caution."

Red (Critical Stock): Immediate action required.

Typography: Likely Inter or Geist. It’s a geometric sans-serif that prioritizes legibility in data-dense environments (like reading medication dosages).
